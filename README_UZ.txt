SMART BUDGET 3D — ANDROID APK LOYIHASI

Bu loyiha mavjud smart_budget_3d_offline HTML ilovasini Android WebView ichida,
internetga ulanmasdan ishlatish uchun tayyorlandi.

APKni telefonning o‘zida bulut orqali yig‘ish:
1. GitHub akkauntingizga kiring: https://github.com
2. New repository yarating (masalan: smart-budget-3d).
3. Ushbu ZIP ichidagi fayllarni repository bosh sahifasiga yuklang.
   Muhim: ZIPning o‘zini emas, ZIP ichidagi papka va fayllarni yuklang.
4. .github/workflows/build-apk.yml fayli ham joyida ekanini tekshiring.
5. Repository ichida Actions bo‘limini oching.
6. "Build Smart Budget 3D APK" workflow ni tanlang va Run workflow bosing.
7. Jarayon tugagach, shu ish (run) sahifasining Artifacts qismidan
   Smart-Budget-3D-APK faylini yuklab oling.
8. Yuklangan ZIPni telefonda oching. Ichidagi app-debug.apk faylini bosing
   va Android so‘rasa, shu manbadan ilova o‘rnatishga ruxsat bering.

Eslatma:
- Bu debug APK; shaxsiy telefonda sinash uchun.
- Play Store uchun alohida release signing kerak.
- Ilova ma’lumotlari WebView mahalliy xotirasida saqlanadi.
- Ilovani o‘chirish yoki uning ma’lumotlarini tozalash ma’lumotlarni yo‘qotishi mumkin.
- Bu loyiha HTML prototipini APK ichiga joylaydi; ilovaning barcha funksiyalarini
  alohida qurilmalarda sinab ko‘rish kerak.
